# Rove Tokens

`@swiftsolve/rove-tokens`: Rove's design tokens. The Figma plugin in
`figma-plugin/` exports the Rove Design System's variables, text styles and
shadows into `src/figma/`, and `npm run build` turns them into `dist/`
(`tokens/` in DTCG, `tokens.css`, `text-styles.css`) and the token reference in
`DESIGN.md`.

## Rules

### Figma is the source of truth; git is the record

Tokens flow one way: designed in Figma, exported into this repo, built,
released, and taken up by Rove. Nothing here writes to Figma.

- **Change a token in Figma, then export and build.** The export writes
  `src/figma/*.json` and the build writes `dist/` and `DESIGN.md` below its
  "Generated by npm run build" marker, so the next run undoes an edit there;
  `DESIGN.md`'s top half is edited directly. Only what Figma can't hold (font
  stacks, easing curves, the focus expressions) is written here, in
  `src/code-tokens.json`.
- **`npm run figma:check` must report `inSync: true`.** It and
  `npm run figma:export` print the plugin's own code (`figma-plugin/code.js`)
  to run through the Figma MCP's `use_figma`, so the plugin's Check tab and an
  agent check the same way. A difference means the repo is behind Figma
  (export again) or was edited directly (undo it, and change Figma).

### Commit only your paths

Other sessions work in this checkout and commit to `main` alongside you.
Stage and commit your own files by name, `git add -A <paths>` then
`git commit -m "…" -- <paths>`, and leave everyone else's changes where they
are.

## Validation

### Check your work

Run `npm run check` before you commit: the build (which refuses a token
without a description), lint (ESLint and Prettier), the WCAG AA contrast check
and the Figma plugin's test (`npm test`). Commit the rebuilt `DESIGN.md` with
the change. Fix what a hook reports.

### What runs on its own

| Stage | Runs |
| --- | --- |
| Each edit (Claude Code, `.claude/settings.json`) | Prettier and ESLint on the file. Refuses a hook skipped, a plain force push and `git reset --hard` |
| Each commit (`scripts/hooks/git/`, on after `npm install`) | ESLint and Prettier on the staged files. `commit-msg` refuses a Claude co-author or "Generated with Claude" line |
| Each release tag (CI, `publish.yml`) | `npm run check`, then publish to npm only if it passes |
