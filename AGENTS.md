# Rove Tokens

`@swiftsolve/rove-tokens`: Rove's design tokens. The Figma plugin in
`figma-plugin/` exports the Rove Design System's variables and text styles into
`src/figma/` and syncs them back, and `npm run build` turns them into `dist/`
(`tokens/` in DTCG, `tokens.css`, `text-styles.css`) and the token reference in
`DESIGN.md`. A Storybook of the tokens lives in `stories/` and `.storybook/`,
and the Figma slideshow export in `scripts/presentation/`. `README.md` has the
details.

## Figma is where tokens are designed; git is the record

A token change can start on either side, but it ships only through this repo:
a commit, `npm run build`, a release. Figma and the repo must agree when it
does.

- **From Figma** (a designer's change): export with the plugin into
  `src/figma/`, or through the Figma MCP's `use_figma` with
  `npm run figma -- export` and then `npm run figma -- save <result.json>`.
  Then build.
- **From code** (your change): edit `src/figma/*.json` or
  `src/code-tokens.json` and build, then make Figma match with
  `npm run figma -- apply` through `use_figma`. Shadows in
  `src/code-tokens.json` are the file's `Shadow/*` effect styles; easing curves
  and the focus outline stay code-only.
- **Either way**, finish with `npm run figma -- check` through `use_figma`. It
  must report `inSync: true`. A `fixable: false` difference (mode order, or a
  variable's collection or type) has to be fixed by hand in Figma; say so.

`npm run figma` prints the script to pass to `use_figma` as `code`, with the
file key in `src/figma/variables.json`. The script is the plugin's own code
(`figma-plugin/code.js`), so the plugin's Sync tab and an agent check the same
way.

Never hand-edit `dist/`, or `DESIGN.md` below its "Generated by npm run build"
marker. Its top half is written by hand.

## Check your work

```bash
npm run check                # build, lint (ESLint + Prettier), DESIGN.md up to date
npm run format               # Prettier, when lint says a file isn't formatted
```

CI runs the same on every release tag.

## Hooks

`npm install` points git at `scripts/hooks/git/`: pre-commit lints and
format-checks the staged files, and commit-msg rejects a Claude co-author or
"Generated with Claude" line. Fix what they report; don't skip them.

`.claude/settings.json` runs `scripts/hooks/claude/`: each edited file is
formatted and linted, and `--no-verify`, a plain force push and
`git reset --hard` are blocked. Other sessions share this checkout, so commit
only your paths (`git commit -m "…" -- <paths>`).

## Releasing

Follow `README.md`: Release. Then bump `@swiftsolve/rove-tokens` in
`../rove` and follow that repo's `AGENTS.md`: Keep the sites in sync.
