# Rove Tokens

`@swiftsolve/rove-tokens`: Rove's design tokens. The Figma plugin in
`figma-plugin/` exports the Rove Design System's variables, text styles and
shadows into `src/figma/`, and `npm run build` turns them into `dist/`
(`tokens/` in DTCG, `tokens.css`, `text-styles.css`) and the token reference in
`DESIGN.md`. This file is the procedures and the rules; `README.md` has the
details.

## Procedures

Each is a skill: Claude Code loads its steps when the task comes up. Other
agents, open the file.

| Task | Skill |
| --- | --- |
| Change a token, text style or shadow, release it, and take it up in Rove | `.claude/skills/change-token/SKILL.md` |

README.md's Update the tokens and Release are the same run for people.

## Rules

### Figma is the source of truth; git is the record

Tokens flow one way: designed in Figma, exported into this repo, built,
released, and taken up by Rove. Nothing here writes to Figma.

- **Never hand-edit an export or a build**: `src/figma/*.json`, `dist/`, or
  `DESIGN.md` below its "Generated by npm run build" marker (its top half is
  written by hand). Only what Figma can't hold (font stacks, easing curves,
  the focus expressions) is written here, in `src/code-tokens.json`.
- **`npm run figma:check` must report `inSync: true`.** It and
  `npm run figma:export` print the plugin's own code (`figma-plugin/code.js`)
  to run through the Figma MCP's `use_figma`, so the plugin's Check tab and an
  agent check the same way. A difference means the repo is behind Figma
  (export again) or was edited by hand (undo it, and change Figma).

### Check your work

Run `npm run check` before you commit: the build, lint (ESLint and Prettier),
then every check in `scripts/checks/` (DESIGN.md up to date, descriptions, WCAG
AA contrast, the Figma plugin). `npm run format` fixes what Prettier reports.
Fix what a hook reports; never skip one. Other sessions share this checkout, so
commit only your paths (`git commit -m "…" -- <paths>`).

## Reference

### What runs on its own

| Stage | Runs |
| --- | --- |
| Each edit (Claude Code, `.claude/settings.json`) | Prettier and ESLint on the file. Refuses a hook skipped, a plain force push and `git reset --hard` |
| Each commit (`scripts/hooks/git/`, on after `npm install`) | ESLint and Prettier on the staged files. `commit-msg` refuses a Claude co-author or "Generated with Claude" line |
| Each release tag (CI) | Build, lint and `scripts/checks/` (`build.yml`); publish to npm (`publish.yml`); the Figma slideshow (`presentation.yml`) |
