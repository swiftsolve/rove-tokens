# Rove Tokens

`@swiftsolve/rove-tokens`: Rove's design tokens. The Figma plugin in
`figma-plugin/` exports the Rove Design System's variables and text styles into
`src/figma/` and syncs them back, and `npm run build` turns them into `dist/`
(`tokens/` in DTCG, `tokens.css`, `text-styles.css`) and the token reference in
`DESIGN.md`. A Storybook of the tokens lives in `stories/` and `.storybook/`,
and the Figma slideshow export in `scripts/presentation/`. `README.md` has the
details.

## Figma is the source of truth; git is the record

Tokens flow one way: designed in Figma, exported into this repo, built,
released, and taken up by Rove. Nothing here writes to Figma. The whole run,
from the Figma change to Rove's resync, is the `change-token` skill
(`.claude/skills/change-token/SKILL.md`); README.md's Update the tokens and
Release are the human version.

- **Never hand-edit an export or a build**: `src/figma/*.json`, `dist/`, or
  `DESIGN.md` below its "Generated by npm run build" marker (its top half is
  written by hand). Only what Figma can't hold (font stacks, easing curves,
  the focus expressions) is written here, in `src/code-tokens.json`.
- **`npm run figma:check` must report `inSync: true`.** It and
  `npm run figma:export` print the plugin's own code (`figma-plugin/code.js`)
  to run through the Figma MCP's `use_figma`, so the plugin's Check tab and an
  agent check the same way. A difference means the repo is behind Figma
  (export again) or was edited by hand (undo it, and change Figma).

## Check your work

```bash
npm run check                # build, lint (ESLint + Prettier), DESIGN.md up to date, descriptions, WCAG AA contrast
npm run format               # Prettier, when lint says a file isn't formatted
```

CI runs the same on every release tag.

## Hooks

`npm install` points git at `scripts/hooks/git/`: pre-commit lints and
format-checks the staged files, and commit-msg rejects a Claude co-author or
"Generated with Claude" line. Fix what they report; don't skip them.

`.claude/settings.json` runs `scripts/hooks/claude/`: each edited file is
formatted and linted, and `--no-verify`, a plain force push and
`git reset --hard` are blocked. Other sessions share this checkout, so commit
only your paths (`git commit -m "…" -- <paths>`).

## Releasing

The `change-token` skill's Release and In Rove steps: stamp the Figma cover,
`npm version`, push the tag, then bump Rove and resync its sites.
