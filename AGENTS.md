# Rove Tokens

`@swiftsolve/rove-tokens`: Rove's design tokens. The Figma plugin in
`figma-plugin/` exports the Rove Design System's variables and text styles into
`src/figma/`, and `npm run build` turns them into `tokens/` (DTCG),
`tokens.css`, `text-styles.css` and the token reference in `DESIGN.md`. A
Storybook of the tokens lives in `stories/` and `.storybook/`, and the Figma
slideshow export in `scripts/presentation/`. `README.md` has the details.

## Figma is the source of truth

To change a token, change it in Figma, export it with the plugin into
`src/figma/`, then run `npm run build`. What Figma can't hold (shadows, easing
curves, the focus outline) lives in `src/code-tokens.json`.

Never hand-edit the generated files: `tokens.css`, `text-styles.css`,
`tokens/`, the values in `src/figma/`, or `DESIGN.md` below its
"Generated by npm run build" marker. Its top half is written by hand.

## Check your work

```bash
npm run check                # build, lint (ESLint + Prettier), DESIGN.md up to date
npm run format               # Prettier, when lint says a file isn't formatted
```

CI runs the same on every release tag.

## Hooks

`npm install` points git at `scripts/hooks/git/`: pre-commit lints and
format-checks the staged files, and commit-msg rejects a Claude co-author or
"Generated with Claude" line. Fix what they report; don't skip them.

`.claude/settings.json` runs `scripts/hooks/claude/`: each edited file is
formatted and linted, and `--no-verify`, a plain force push and
`git reset --hard` are blocked. Other sessions share this checkout, so commit
only your paths (`git commit -m "…" -- <paths>`).

## Releasing

Follow `README.md`: Release. Then bump `@swiftsolve/rove-tokens` in
`../rove` and follow that repo's `AGENTS.md`: Keep the sites in sync.
